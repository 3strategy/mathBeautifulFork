## נושאים מתקדמים בתחביר לולאת `for`

{: .box-note}
**הערה**: לולאת `for` בשפת #C מאפשרת תחביר גמיש במיוחד, וניתן להשתמש באלמנטים לא שגרתיים כדי לפתור בעיות בצורה יצירתית. בפרק זה נחקור תבניות מתקדמות ונדגים שימושים בעזרת דוגמאות קצרות.


### שמירה על ערך האינדקס לאחר הלולאה

ב-C#, משתנה הלולאה שומר את ערכו גם לאחר סיום הלולאה.

```csharp
int i;
for (i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
Console.WriteLine("האינדקס לאחר הלולאה הוא: " + i);
```
שאלה: מה יודפס?

תשובה:

```csharp
0
1
2
3
4
האינדקס לאחר הלולאה הוא: 5
```

אתחול מרובה בלולאה אחת
ניתן לאתחל כמה משתנים יחד בתחילת הלולאה.

```csharp
for (int i = 0, j = 10; i < j; i++, j--)
{
    Console.WriteLine($"i = {i}, j = {j}");
}
```

{: .box-success}
בלולאה זו השתמשנו בתחביר מומלץ ונח לשימוש לשירשור מחרוזות (string concatenation). תחביר דומה משמש גם בפייתון כאשר משתמשית בתחילית f' לפני המחרוזת. לא קיים ב-JAVA

תנאים מרובים ועדכונים מרובים
ניתן לכתוב תנאי הפסקה מורכב יותר, כולל פעולות רבות בכל שלב.

```csharp
int a = 0, b = 10;
for (; a < 5 && b > 5; a++, b -= 2)
{
    Console.WriteLine($"a={a}, b={b}");
}
```

דילוג על האתחול בלולאה
כאשר משתנה האינדקס מאותחל קודם, ניתן לדלג על שלב האתחול:

```csharp
int i = 3;
for (; i < 6; i++)
{
    Console.WriteLine(i);
}
```

דילוג על שלב ההוספה
ניתן לשים את עדכון האינדקס בתוך גוף הלולאה:

```csharp
for (int i = 0; i < 3;)
{
    Console.WriteLine(i);
    i++; // העדכון בתוך הגוף
}
```

שינוי ערך i בתוך הלולאה כדי "להאריך" אותה
שימוש בטריק זה נפוץ כאשר רוצים לחזור על אינפוט שנכשל בבדיקה.

```csharp
for (int i = 0; i < 3; i++)
{
    Console.Write("הכנס מספר חיובי: ");
    int n = int.Parse(Console.ReadLine());
    if (n <= 0)
    {
        Console.WriteLine("לא תקין, נסה שוב");
        i--; // מבטל את הסבב הנוכחי
    }
}
```

שימוש ב-continue כדי לדלג על שאר הקוד בלולאה
```csharp
for (int i = 0; i < 5; i++)
{
    if (i % 2 == 0)
        continue; // דילוג על מספרים זוגיים

    Console.WriteLine(i); // יודפסו רק אי-זוגיים
}
```

קיצור forr — לולאה יורדת (מהסוף להתחלה)
קיצור שימושי ב-Visual Studio ללולאה הפוכה:

```csharp
for (int i = 3 - 1; i >= 0; i--) // חשוב לזכור תחביר זה לקורס הבא
{
    Console.WriteLine(arr[i]);
}
```

מה התוצאה של לולאה כזו?

תשובה:

```
2
1
0
```

טבלת סיכום
תחביר	תיאור
for (int i = 0, j = 2; ...)	אתחול משתנים מרובים
for (; i < 10;)	דילוג על שלב האתחול
for (int i = 0;; i++)	לולאה אינסופית (חסרה תנאי עצירה)
i-- בתוך הלולאה	הרחבת הלולאה במקרה חריג
continue	דילוג על שאר גוף הלולאה
{: .box-success} טיפ: תבניות אלו שימושיות במיוחד בפתרון בעיות קלט, אימות נתונים, ובשליטה מתקדמת על זרימת הקוד.
